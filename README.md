# Standophæng — visningsudgave

3D-visning af udstillingsstanden. Én selvstændig HTML-fil: 3D-motor, malerier,
inventar og priser ligger inde i filen, så der er intet at installere og intet
byggetrin.

Udgives med GitHub Pages fra `main`. For at opdatere: lav en ny visningsudgave i
redigeringsværktøjet, overskriv `index.html` og commit.
